# Spec Kit Workshop

This project contains a workshop to introduce Speckit and illustrate its use.
There's also a new project template which can be used to seed a new SpecKit project.

- [The 90-minute workshop](index.md) - a hands-on introduction: the
  specify -> plan -> tasks -> implement -> converge loop, demoed on a
  pet store and practiced on an order-placement feature with a hidden
  invariant.
- [`new-project-template/`](new-project-template/) - a seedable project template - a 
  requirements source, a roadmap, and requirement-phrase and digest
  checks - that sets up a fresh Spec Kit project with one command.
